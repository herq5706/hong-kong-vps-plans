## 线路和 IP 的差别在哪里

这两项决定同一份配置能不能用，而它们恰恰是最容易被略过的地方。

**线路看的是回国方向走哪条路。** 大陆到香港的物理延迟本来就低，直连普遍在 30 到 50ms，没做优化的线路大概 40 到 80ms，欧美节点动辄 150ms 以上。真正的差别出现在晚高峰：电信走 CN2、联通走 9929、移动走 CMIN2 的机器，三网各走各的最优路径，掉速少；BGP 精品是机房自己做多线接入，比单线强，比三网精品弱一档；国际网络只保证到香港本地的出口质量，回国要绕，胜在便宜。

LightLayer 把这件事直接写进了产品结构：香港金牌机型的带宽分成“优化 / 普通回国 / 国际”三档，选哪档决定价格。这是最直白的线路定价方式，你不需要猜“优化”背后是 CN2 还是 9929，只需要知道优化档贵、国际档便宜。5 美元那三款云主机没有标注属于哪一档，下单前必须确认。

**IP 看的是身份，不是速度。** 机房段的数据中心 IP 在流媒体和电商平台的风控里容易被标成代理；香港本地宽带运营商签发的住宅 ISP IP 标签更干净，TVB、Netflix 港区、Cityline 票务这类服务过检率高得多。LightLayer 的香港云主机公开页面没有写 IP 属性，如果你的用途是解锁港区服务或养社媒账号，这一项要在下单前问清楚，别默认它是住宅 IP。

**建站、跳板机、远程办公。** 你要的是回国方向稳定，直接选优化档带宽。1 核 1G 跑一个日 PV 几千的 WordPress 够用，香港节点不需要备案，开通即用。这类用途对 IP 属性没要求，5 美元那档就能起步。

## 常见问题

**香港 VPS 要备案吗？** 不需要。香港不在大陆备案体系内，机器开通就能绑域名解析，这是香港节点相对内地机房最直接的优势。

**KVM 和 OpenVZ 差在哪？** KVM 是完整硬件虚拟化，资源独占，能跑 Docker、WireGuard、自定义内核模块；OpenVZ 共享宿主内核，上面这些能力受限。日常使用选 KVM，只有预算压到极低且只跑简单脚本才考虑 OpenVZ。LightLayer 的架构公开页面没标，下单前确认。

**流量超了怎么算？** 各家口径不同，有的限速，有的按 GB 额外收费。1TB 流量对普通建站足够，跑下载或视频中转就会吃紧。超限规则要问客服，别按“不限流量”的直觉理解。

**能装 Windows 吗？** LightLayer 的公开页面没有标注。需要 Windows 的话先问，别先买后试。

**支持支付宝吗？** 公开页面没写支付方式，结算页看。国内用户对这一项比较敏感，值得在下单前确认。

**开通要多久？** 活动说明里提到未支付订单保留 1 小时，说明下单到付款是自动流程。实际开通时间以订单页提示为准。
